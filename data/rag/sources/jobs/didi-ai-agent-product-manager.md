# 滴滴 AI Agent 产品经理

## 岗位方向

岗位负责企业内部 Agent 平台，重点是复杂任务自动化、稳定交付结果和可复用通用能力。

## 核心职责

- 规划工具调用、上下文与 Memory、任务编排等 Agent 核心模块；
- 把业务需求抽象为 Prompt、Workflow 和 Skill 等可复用能力；
- 建设任务成功率、产物质量、路由与工具调用成功率、耗时稳定性等评测体系；
- 将 Tool Use、Context Engineering、Eval 与 Benchmark 转化为产品能力。

## 可观察的能力要求

候选人需要能用 Prompt、API、MCP、脚本或原型验证假设，理解 Agent 执行机制、接口边界和异常处理，并能用数据进行效果归因。
