# 京东 AI Agent 产品经理

## 岗位方向

岗位面向企业级 AI Agent 业务应用平台，希望让非技术用户通过低代码或自然语言构建、部署和管理 Agent。

## 核心职责

- 定义编排引擎、记忆/RAG、插件与 Tools、多模态交互的产品边界；
- 将零售、物流和金融场景抽象为通用组件；
- 设计 Agent Marketplace、开发者协议、Skills 和组件生态；
- 建设端到端 Eval、线上效果追踪、调优和成本治理。

## 可观察的能力要求

岗位要求理解 LLM、Prompt Engineering、RAG 和 Function Calling，并具备低代码平台、复杂 B 端系统或 AI 产品的实践经验。
