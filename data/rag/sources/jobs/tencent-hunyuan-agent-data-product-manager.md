# 腾讯混元大模型数据策略产品经理-AI Agent/Coding方向

## 岗位方向

岗位聚焦大模型在 AI Agent、Coding 和专业垂类中的后训练数据策略与质量体系。

## 核心职责

- 设计行业深度、复杂推理和交互合成相关的数据标准；
- 连接算法、数据生产和标注团队，建立清洗、合成、标注和交付链路；
- 建立数据质量评估体系，支持 Agent 与 Coding 能力持续迭代。

## 可观察的能力要求

该岗位更偏数据策略产品，强调后训练数据、质量评估、流程设计和算法协同，而非单纯的前台交互设计。
