# CareerPilot 产品指南

CareerPilot 面向正在探索职业方向的高校学生与毕业早期青年。它不替用户选一个“正确答案”，而是帮助用户积累对自己的理解、查证外部信息，并用低风险行动获得现实证据。

## 一句话产品闭环

```text
表达 → 理解 → 形成职业假设 → 查证 → 小行动 → 现实反馈 → 更新理解
```

它与普通职业问答产品的主要差别，是这条闭环可以跨会话延续：对话不是终点，行动结果也不是孤立的任务记录，而会成为后续方向判断的新证据。

## 1. 从一句真实想法开始

用户不需要先想清楚职业名称，可以直接说：

> “我最近做社团活动时很喜欢协调大家，但一想到把它当工作又有点抗拒。”

Agent 会根据用户当前目标，在四种支持模式间切换：

| 模式 | 什么时候使用 | Agent 会做什么 | 不会做什么 |
|---|---|---|---|
| `listen` | 只想倾诉、还没准备好分析 | 具体地回应感受，最多问一个轻问题 | 不检索、不创建任务 |
| `organize` | 想把混乱的事情理清 | 区分事实、感受、担忧、猜想和未知 | 不替用户下职业结论 |
| `explore` | 想比较方向或查资料 | 组织假设与证据，按需检索职业知识 | 不把检索结果当成个人答案 |
| `act` | 已准备好推进 | 提出一个低压力、可验证的行动 | 不绕过确认执行外部写入 |

用户显式说“先听我说”“帮我梳理”或“给我一个行动”时，显式选择优先于自动判断。

## 2. 让系统记住真正重要的事

对话结束后，系统会从原始事件中提炼记忆候选，但不会把每句话都写成永久画像。

- 经历保留发生时间和来源，不会自动升级为人格结论。
- 稳定事实、明确偏好、长期约束和目标才适合跨会话复用。
- “我今天什么都做不好”这类短暂负面表达默认不进入长期记忆。
- 新表达与旧记忆冲突时，最新的用户明确表达优先，旧版本可以被替代或撤回。
- 后端提供查看、纠正、暂停、恢复和删除记忆的完整接口；当前产品界面主要通过对话与 Dreaming 处理候选洞察，独立记忆管理入口仍在完善。

Dreaming 会在有足够证据时整理重复、冲突和变化，生成每日回顾或候选假设。它只能引用已有事件，不能凭空创造经历，也不能直接替用户建立方向、任务或日历事件。

## 3. 把“可能喜欢”变成可验证的方向

当对话出现职业方向信号时，Agent 会提出候选，由用户决定是否加入罗盘。一个方向不是标签，而由四类信息组成：

- 支持它的个人经历和外部证据；
- 与它冲突的反证；
- 当前还不知道的问题；
- 随证据变化的信心，而不是永久分数。

知识库把岗位信息、历史面试经验、学习资料和个人文档分开呈现。稳定知识优先使用本地资料；当前招聘状态、截止日期等强时效事实需要重新核验。没有足够来源时，Agent 应明确停止，而不是补造一个看起来完整的答案。

## 4. 用一小步获得现实反馈

用户确认方向后，可以从罗盘开启一段航程。每轮默认只推进一个主行动，例如：

- 用 20 分钟拆解一个真实岗位描述；
- 找一位从业者准备三个访谈问题；
- 做一个微型作品，观察自己喜欢的是主题还是工作方式；
- 记录一次项目中让自己投入或消耗的具体时刻。

行动必须有目标、预计时长和完成标准。完成、延期和取消都属于有效反馈；系统不把“没有完成”简单解释为缺乏自律。

涉及日历、邮箱、飞书等外部写操作时，流程固定为：

```text
生成预览 → 用户确认 → 执行 → 验证结果
```

MVP 不做自动投递、代聊 HR 或未经确认的外部发送。

## 5. 页面与任务对应关系

| 页面 | 主要问题 | 主要产物 |
|---|---|---|
| 今日 | 我今天该关注什么？ | 今日线索、进行中的行动、回顾入口 |
| 对话 | 我现在到底在想什么？ | 支持性回应、记忆候选、方向信号 |
| Dreaming | 最近有哪些重复、冲突或变化？ | 可确认的洞察、假设与每日回顾 |
| 罗盘 | 这个方向有哪些证据和未知？ | 候选方向、证据、反证、信心 |
| 航程 | 下一步如何在现实中验证？ | 小行动、状态与现实反馈 |
| 知识库 | 外部世界有什么可靠依据？ | 岗位、面试、学习与个人资料 |

## 6. 产品原则与边界

1. **情绪优先于效率**：难受时先接住，不因为“可以行动”就强迫行动。
2. **证据优先于标签**：职业方向来自经历、反证和现实反馈，不来自一次测评的固定结论。
3. **记忆服务于成长**：记住有长期价值的内容，并让用户能够纠正和删除。
4. **行动由用户控制**：内部候选可以自动生成，外部写操作必须确认。
5. **不知道就诚实停止**：资料不足、来源冲突或工具失败时明确说明边界。

## 7. 当前版本边界

CareerPilot 目前处于 MVP 阶段，已打通对话、记忆、方向、知识、航程与外部动作确认的主链路。它不是临床心理服务、招聘平台或自动求职机器人；面向真实用户开放前，仍需扩充端到端评测、真实用户研究、可观测性与生产运维能力。
